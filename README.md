# 🚀 NUML Career Hub

NUML Career Hub is a simple web application designed to help NUML students quickly discover software houses in Islamabad and access their official LinkedIn and Career pages from one place.

Instead of manually searching for companies, students can use this platform to explore opportunities and connect directly with software houses.

---

## ✨ Features

- 🔍 Search software houses by name
- 🏢 Browse software houses located in Islamabad
- 💼 Open official LinkedIn pages
- 🚀 Open official Career pages
- 📱 Fully responsive design
- 🌙 Modern dark theme
- ⚡ Fast and lightweight interface

---

## 🎯 Purpose

This project was built to make internship and job hunting easier for NUML students.

The platform provides quick access to:

- Official LinkedIn Pages
- Official Career Pages
- Islamabad Software Houses

Everything is available in one place.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/numl-career-hub.git
```

Go to the project folder

```bash
cd numl-career-hub
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
